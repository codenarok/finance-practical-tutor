Finance Practical Tutor – Local Run Instructions
===============================================

Prerequisites
-------------
1. Python 3.12+
2. Docker (optional, only if you want Postgres via docker-compose)
3. Ollama installed locally (`brew install ollama` on macOS or follow https://ollama.com/download)


1. Create & Activate a Virtual Environment
------------------------------------------
```
python3 -m venv .venv
source .venv/bin/activate
```


2. Install Python Requirements
------------------------------
```
pip install --upgrade pip
pip install -r requirements-dev.txt
```


3. Start Postgres
-----------------
Option A – Docker (recommended for quick local use):
```
docker compose up db
```

Option B – Use your own Postgres instance and create a database (e.g., `fintutor`).

Option C – Skip Postgres and use SQLite: set `DATABASE_URL=sqlite:///./dev.db` in step 5.


4. Start Ollama Server and Model
--------------------------------
1. Launch the Ollama daemon:
   ```
   ollama serve
   ```
2. In a separate terminal, pull the model you configured (default `llama3`):
   ```
   ollama pull llama3
   ```
Keep the Ollama server running; the FastAPI app calls it at `http://localhost:11434`.


5. Configure Environment Variables
----------------------------------
Copy `.env.example` to `.env` and fill in `SECRET_KEY`. It must be 32 characters or more;
the app refuses to start otherwise. Generate one with:
```
python3 -c "import secrets; print(secrets.token_urlsafe(48))"
```


6. Initialize the API
---------------------
```
uvicorn app.main:app --reload
```
The startup hook auto-creates tables (with retry) using the configured DB URL.


7. Use the App
--------------
1. Visit `http://localhost:8000/static/index.html` to register or log in.
2. After login, you are redirected to the chat UI (`chat.html`). Pick a level and topic, then ask.
   Replies stream in as they are written, and follow-up questions keep the earlier conversation.
3. Accounts persist in the database; hashed passwords ensure security even after server restarts.


8. Optional – Full Stack via Docker Compose
-------------------------------------------
To spin up API + Postgres + Ollama in one go (SECRET_KEY must be set, in `.env` or inline):
```
docker compose up --build
```
The first run downloads the model before the app starts. The API is then on `http://localhost:8000`.


9. Run the Tests
----------------
```
python -m pytest
```
No Postgres or Ollama needed; the suite uses SQLite and a stand-in model server.

Troubleshooting
---------------
- If the chat says the tutor is temporarily unavailable, verify `ollama serve` is running and the model is pulled.
- A 429 response means the rate limit was hit; wait a minute.
- For DB connection errors, ensure Postgres is reachable and credentials match `DATABASE_URL`.
- Restart `uvicorn` whenever `.env` values change (settings are cached).
